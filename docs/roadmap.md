# Beyond v0.1

1. Validate native Codex interactive/noninteractive launch on an unrestricted host,
   including filesystem and shell-write probes, real outcome import, and manual
   VS Code layout. Add version-gated runtime diagnostics without loosening policy.
2. Validate the initial Claude Code adapter on a supported host, including its
   native model-assisted sandbox probe, real Worker execution, and outcome handoff.
   Then evaluate native hooks, skill/MCP discovery, and mixed-provider operation
   separately without weakening bounded Worker permissions.
3. Add an external work provider only when authentication and authoritative-state
   semantics can be tested. Keep manual work useful and source identities portable.
4. Improve work recovery across machines: safely attach reviewed existing branches,
   richer verification receipts, and explicit ownership coordination for shared work.
5. Validate organizational reconciliation in its authorized environment, preserve
   existing behavior until parity, and promote only approved general requirements.

Background service supervision, a custom editor extension, a connector platform,
automatic context ingestion and automatic publication are not v0.1 goals.
